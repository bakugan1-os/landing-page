# Bang & Olufsen landing page

A responsive landing page for the Bang & Olufsen audio brand.

- [DEMO LINK](https://bakugan1-os.github.io/landing-page/)

## Tech stack

- Semantic HTML5
- SCSS organised with the BEM methodology, one block per file
- Parcel 2 as the bundler
- ESLint, Stylelint and LintHTML for code quality

## Features

- Mobile-first layout with tablet (576px) and desktop (992px) breakpoints
- Burger menu built entirely in CSS on the `:target` pseudo-class, no JavaScript
- Fullscreen hero section
- Product and category grids that reflow across breakpoints
- Contact form with native validation
- SVG icons

## Getting started

```bash
git clone https://github.com/bakugan1-os/landing-page.git
cd landing-page
npm install
npm start
```
